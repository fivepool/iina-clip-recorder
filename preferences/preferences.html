IINA Clip Recorder

Export settings are captured when a new clip selection starts. Shortcut changes reach open player windows in about one second.

Shortcut

Enter one modified key, for example Cmd+R, Command+R, ⌘R, or Ctrl+Alt+C. Command aliases are stored canonically as Meta. A changed shortcut takes effect after restarting IINA or reloading the plugin.

Runtime status Waiting for a player window…

Output formats

Enable MP4, GIF, or both. At least one output format must remain enabled.

MP4 resolution

1080p fits the video inside 1920×1080 without upscaling. Full Resolution preserves the source display size.

When enabled, MP4 clips contain video only. This does not affect GIF.

GIF options

Resolution
Frame rate

Full-resolution, source-rate GIFs can be extremely large and may take substantially longer to encode.

Destination

Use ~, a path beginning with ~/, or an absolute path beginning with /. The directory is created when an export starts.

FFmpeg

Leave blank to auto-detect FFmpeg, or enter a path beginning with ~/ or /. The executable is checked when the next clip selection starts.
